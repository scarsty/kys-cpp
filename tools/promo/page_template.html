缘起 · 这是什么游戏

关于本局棋

《金群自走棋》是开源项目「金庸群侠传复刻版」（kys-cpp）中的自走棋玩法。擂鼓山上，苏星河奉师命守护珍珑棋局——棋盘之上，江湖群侠化为棋子，各展所长，自行厮杀；而你，才是执子之人。

招募棋子、排兵布阵、凑齐羁绊、授予神兵内功，随后坐看群侠自动交锋。从江南七怪到扫地老僧，从华山五绝到天龙三兄弟，金庸笔下的英雄尽在一盘棋中。

纯单机、无内购、失败零惩罚，输了随时卷土重来。本页随 PC 版一同分发；若想立即体验，网页版打开即玩（推荐 Edge / Firefox / Chrome / Opera 浏览器），安卓与 Windows 亦有对应版本。

核心规则详解

比游戏内「游戏说明」更展开一些；完整数值仍以游戏内为准

棋子与升星

  • 棋子分一至五费，售价即费用（1费1金 …… 5费5金），越高费越难刷出。
  • 三枚相同一星合成二星，三枚二星再合三星；每颗额外星大幅提升属性，另有固定加成，升星后脱胎换骨。
  • 出售按 费用 × 3星级-1 全额返还，换阵不亏。
  • 胜场成长：打赢主线、或首次通关远征时，只有活下来的棋子个人胜场 +1。以普通难度当前配置为例，每个胜场值生命 +%%Y:nb:棋子成长.每胜生命%%、攻击 +%%Y:nb:棋子成长.每胜攻击%%、防御 +%%Y:nb:棋子成长.每胜防御%%、各项兵器熟练度 +%%Y:nb:棋子成长.每胜兵器%%、轻功 +%%Y:nb:棋子成长.每胜轻功%%；带小数的按总胜场累计后向下取整。合成时只继承三枚棋子里最高的胜场，不会相加；部分羁绊还会按现有胜场再追加成长。

经济与等级

  • 开局揣着 %%Y:nb:经济.初始金币%% 金；刷新商店一次 %%Y:nb:经济.刷新费用%% 金；%%Y:nb:经济.购买经验费用%% 金可买 %%Y:nb:经济.购买经验数量%% 点经验。
  • 主线打赢后，按开战前存款的 %%Y:nb:经济.利息百分比%%% 发利息，最多 %%Y:nb:经济.利息上限%% 金——打输了没有，远征也不发。
  • 普通关卡胜利 +%%Y:nb:经济.战斗经验%% 经验；打赢强敌（Boss）+%%Y:nb:经济.Boss战斗经验%% 经验，外加一笔金币。
  • 升级既能多上人，也会改变商店各费阶的出现权重——高费棋子得等级上去了才刷得出来。

商店刷新与拒绝名单

  • 刷新时先按你当前等级抽费阶，再从该费阶还能出现的角色里挑人；这个费阶要是没人可挑，权重就匀给其他费阶。
  • 这轮商店没买走的一至四费角色，会进一次性的拒绝名单——下一次刷新不会原样再来；五费大佬不受此限。
  • 锁定商店后，打赢主线也不会自动换货；解锁本身同样不换——想要新货，要么手动刷新，要么再赢一场主线。
  • 禁棋只管以后刷出来的商店；已经摆在货架上的棋子照买不误。

失败零惩罚 · 逆天改命

  • 战斗失败不扣金币、不扣生命、不掉棋子，直接回到整备阶段。
  • 换阵容、练级、买装备，收拾好了再战，直到打过去为止。
  • 也可以花 %%Y:nb:经济.逆天改命费用%% 金逆天改命，把下一场的敌方阵容和随机种子重抽一遍。
  • 赢下全部主线关卡即「恭喜通关」；通关之后，远征挑战还能接着打。

第 %%Y:nb:无羁绊关卡%% 关的敌人没有羁绊，开局可以放心稳扎稳打；逆天改命改的是敌方阵容与战斗随机种子，地图不保证会换。

规则与数值的关系

费用、成长、商店权重、关卡数、奖励进度，这些都写在难度配置里；角色武功、羁绊、装备、内功则各有各的内容配置。本页讲的是系统怎么运转，具体数值还是以当前版本游戏内一览为准。

肆

羁绊系统

同门同路，其利断金

同羁绊的棋子一起上阵，凑够人数就点亮对应档位。要注意：大部分属性和被动只加在真正计入羁绊的成员身上；标了「全队」的才雨露均沾；治疗光环这类效果，则是由成员当源头去照顾队友。这里面还有三个门道：

  • 星级羁绊：成员每多一颗星即多计一人——如江南七怪，一枚三星棋子按三人计。
  • 反向羁绊：「独行」会从已上阵的独行成员中选费用最高者独享效果；队伍仍可搭配其他非独行角色。
  • 装备计作：部分装备让佩戴者「计作」某羁绊成员，缺一角也能成阵；同一角色不会因此重复计数。

五绝

不用凑齐五人：上阵两名五绝，五绝成员就有攻防和速度加成；凑到四名数值更猛，还额外给一层能吃掉控制帧数的僵直护盾。

天龙三兄弟

乔峰、段誉、虚竹三人聚首，兄弟三人同享大量生命与命中回蓝——只加他们仨，可不是全队加成。

神雕侠侣

杨过、小龙女一起上阵后，我方第一次有人被打到低血时触发玉女素心，二人短时间内攻击暴增。

丐帮

打赢主线时，场上至少得有一名丐帮成员活着，才发这笔额外金币；发多少，看羁绊档位和存活成员里的最高星级。

智将

每赢一场主线就攒一次免费刷新，不用会一直留着；高阶还能自选战场，并明明白白给全队加生命、攻击与防御。赵敏、黄蓉皆在其列。

红颜

红颜看的是名单而不是性别——只有在配置名单里的角色才算数，可不是随便上几个女将就能成阵。成员能带来治疗光环、受治疗加速与冷却干扰，高档位才追加攻击冷却延长。

独行反向羁绊

独行侠上了好几个，也只有费用最高的那位独享攻速防加成；其他非独行队友不碍事。等他战至最后，还会再涨攻击与格挡。

江湖龙套

杂鱼的逆袭：成员阵亡时殉爆伤敌，人越多炸得越狠。龙套也有春天。

装备与内功

神兵利器，绝世心法

装备怎么来

  • 推主线会多次触发装备奖励，给几个候选、最高到几层都由难度配置决定。点「刷新更多选项」不会丢掉原候选，只会追加新的；最后要是挑了新候选，才收这笔刷新费。
  • 远征挑战的通关奖励中也包含装备。
  • 第 %%Y:nb:神兵商店.通关后%% 关（困难 %%Y:hb:神兵商店.通关后%% 关）后开放神兵商店，只售四阶传说装备，每件 %%Y:nb:神兵商店.价格%% 金（困难 %%Y:hb:神兵商店.价格%% 金）。

全部 %%C:equip%% 件装备的效果与专属加成，以游戏内「装备管理」为准。

装备怎么用

  • 每枚棋子能带武器、防具各一件，装新的自动换下旧的。
  • 许多装备对特定角色有专属加成：如灭绝师太持倚天剑暴击拉满，黄蓉、洪七公、乔峰持打狗棒攻击远程化。
  • 部分装备计作羁绊：七星剑计作全真教、真武剑计作真武七截阵、佛心甲计作少林寺……凑阵神器。
  • 升星合成时，每个装备槽只留层级最高那件，其余自动回库存；卖棋子时装备也会自动卸下来。

内功心法

每击败一位强敌（每 %%Y:nb:进度.Boss间隔%% 关一位），就能从随机 %%Y:ng:选择数量%% 本还没学过的内功里挑一本；强敌越靠后，能挑的层级越高。刷新不会丢原候选，只会追加——最后若挑了新增的那本，才加收 %%Y:ng:刷新费用%% 金。内功一经习得，全队生效，后期阵容强不强，很大程度就看它了。

共 %%C:neigong%% 种内功、分四个层级，具体效果以游戏内「棋局总览 → 查看内功」为准。

远征挑战

不占主线回合的额外试炼

共 %%C:challenge%% 关额外挑战，整备阶段只要手里有出战棋子就能打，输了不罚，也不耽误主线进度。每关奖励只能领一次；给几个候选看关卡配置，并非固定三选一，可能是金币、棋子、升星、内功或装备——哪项当前没有合法目标，那一项就干脆不出现。从单挑三星乔峰的「聚贤庄内」，到全员三星神装的「九阳宗师」，一关比一关难缠。

挑战小贴士

  • 挑战前记得先选好出战阵容。
  • 前期优先打「聚贤庄内」「慕容世家」，奖励的升星与棋子能快速成型。
  • 后期关卡全员三星还带神装，是检验阵容的试金石。
  • 奖励关卡各有侧重，缺什么补什么。

江湖锦囊

老玩家的经验之谈
  • 攒钱吃息：主线胜利才按开战前存款结算利息，上限 %%Y:nb:经济.利息上限%% 金。开战后想攒就晚了——开战前就想好，这笔钱留着吃息还是换成即时战力。
  • 锁定商店：遇到想要却买不起的棋子，锁定留到下回合，别硬刷新。
  • 看中的趁早买：没买走的一至四费角色，只是下一次刷新不会立刻再来；拒绝名单又不是永久黑名单，五费大佬更是来去自由。
  • 卖棋不亏：出售全额返还，前期打工棋子放心换。
  • 连败不慌：失败零惩罚，先把等级和装备补起来再战，或花 %%Y:nb:经济.逆天改命费用%% 金逆天改命换个对手。
  • 羁绊优先：低费棋子凑出关键羁绊，往往强过散兵游勇的高费棋子。
  • 智将理财：智将羁绊每赢一场主线送一次免费刷新，不用就先留着——但不会越攒越多。
  • 丐帮开源：丐帮成员得活到主线胜利结算才产金；别让唯一的丐帮棋子太早倒下。
  • 升级再追梦：五费宗师只在高等级商店出现，想追张三丰、扫地老僧先升级。
  • 装备给对人：专属装备配专属角色（倚天剑给灭绝、打狗棒给黄蓉），才能触发角色限定的额外效果。

自动战斗机制

供复盘与查证的战斗参考

开战后没人闲着：所有棋子按帧同时行动——接敌、出招、打出近战判定或放飞投射物，再一一结算命中、伤害与状态。这一章讲的是这些机制怎么串起来；具体帧数与倍率可能随版本调整，不必死记。

熟练度、轻功与冷却

每门武功都有类别，出手时吃对应的熟练度——拳掌武功看拳掌，御剑武功看御剑，依此类推。一招用完隔多久才能再来？先取这次攻击形态的基础冷却，多数形态下熟练度越高、冷却越短，但每种形态都有下限，快不到哪去；轻功接着再按上限往下压；额外的冷却缩减或冷却延长，最后才登场修正。这些属性只管「两招之间隔多久」，并不会让出招、收招的动作本身变快——前摇后摇该多久还是多久。

内力与绝招循环

内力从哪来？平常出招、自然恢复、打中敌人、挨打损血都会涨，回内加成还能让涨得更多。内力一满，棋子就自动把整管内力打成绝招。中了封内，持续期间一切回内手段都会失灵，下一发绝招只能往后拖。至于绝招到底强化成什么样，得看它的实际攻击形态与具体效果——可没有「伤害翻倍」这种通用好事。

前摇与后摇如何决定

  • 前摇看的是这次实际采用的攻击形态，跟武功叫什么名字无关。近战、追踪弹、直线弹、突进各有各的基础施放帧；出手瞬间还会上下浮动一丝丝，免得全场棋子齐刷刷同帧出手，跟排练过似的。
  • 前摇走完才算真正出手：近战这时才生成命中判定，远程这时才放出投射物，突进这时才冲出去。目标要是在这当口已经没了，这一下可能直接收招，也可能按该形态的规则另找目标。
  • 后摇是出手后那点收势时间。普通攻击的收势大家都一样长，突进则按自己的冲势收尾；收完势就能重新走位——但别误会，这不代表冷却已经转好。
  • 总冷却从动作一开始就同步倒数，前摇后摇都算在里面；冷却归零、当前动作也做完，棋子才能接下一招。所以一招的完整节奏，可不是「前摇 + 后摇 + 冷却」三段简单相加。

「点 / 线 / 十字 / 面」在自走棋里的实际解释

这些名字来自原版回合制武功资料；自走棋是即时战斗，会把它们转换成另一套打法——可别拿原版的格子范围往上套。

资料范围自走棋实际行为绝招时的主要变化
点（0）近身肉搏；连续普通近战打到第三下，会变成一记追击式的强化打击。这一击必定强化，还会补上一记慢半拍的近身溅射。
线 / 十字（1 / 2）目前都会变成直线穿透的投射物，顺带几枚较弱的扇形侧弹；「十字」可不会真往上下左右各射一条线。侧弹更多，但仍是一片朝目标方向展开的穿透弹幕。
面（3）变成追踪投射物，盯着选定目标或附近的备选目标追，并非全屏轰炸。基础追踪弹从一发变两发；想要更多追加弹，得看武功、羁绊或装备的本事。

部分羁绊与装备还会带来远程化、滑步攻击、闪击、追加弹、连锁弹、反弹这些本事，把上面的基础行为改出各种花样。

一次命中如何结算

  • 先拿攻击、武功威力和目标防御算出基础伤害；有穿甲的话，参与计算的防御先打个折。
  • 投射物飞得越久，威力略微衰减；从侧面或背后命中还有额外伤害——所以站位和混战中的朝向真不是小事。
  • 然后才轮到一堆修正挨个结算：熟练度差、技能增伤、暴击、固定加减伤、百分比减伤、护盾、单次承伤上限。
  • 这一下也未必打得实：闪避让它直接落空，格挡能整下取消；远程攻击还可能被弹反，甚至和敌方投射物在空中互相抵消、削弱。

僵直、眩晕与低血保护

  • 被主投射物或近战打中会短暂僵直，绝招主命中的基础僵直更长；眩晕、击退、封内、中毒、流血则来自具体效果。
  • 僵直抗性按比例缩短被控时间；护盾能提供额外抗性，僵直护盾则先替你吃掉一定控制帧数。
  • 血低于一定比例后，棋子不会再中新的僵直或眩晕——给残血留条活路，免得被一路控到阵亡。
  • 每次施放、命中、伤害、状态、抵消与阵亡都带帧号写进战斗日志；这一局输在接敌、输出循环还是控制链，翻翻日志就有数。
