升星與金幣

棋子與升星

  • 棋子分一至五費，費用即購買價格。
  • 三枚同名一星合成二星，三枚二星合成三星，升星提高屬性。
  • 出售按 費用 × 3星級-1 全額返還。
  • 勝場成長：主線勝利或首次通關遠征，所有出戰棋子勝場 +1。標準難度每勝：生命 +%%Y:nb:棋子成長.每勝生命%%、攻擊 +%%Y:nb:棋子成長.每勝攻擊%%、防禦 +%%Y:nb:棋子成長.每勝防禦%%、兵器熟練度 +%%Y:nb:棋子成長.每勝兵器%%、輕功 +%%Y:nb:棋子成長.每勝輕功%%。小數累計後向下取整，合成只繼承最高勝場。
  • 晚成：讓 %%Y:talents:晚成.勝場成長受加成比例%%% 的勝場成長參與星級與其他百分比加成；一般天賦的勝場成長不受星級倍率放大。

經濟與等級（標準）

  • 開局 %%Y:nb:經濟.初始金幣%% 金；刷新 %%Y:nb:經濟.刷新費用%% 金；%%Y:nb:經濟.購買經驗費用%% 金買 %%Y:nb:經濟.購買經驗數量%% 經驗。
  • 主線勝利按開戰前存款的 %%Y:nb:經濟.利息百分比%%% 發利息，上限 %%Y:nb:經濟.利息上限%% 金；失敗與遠征不發。
  • 普通關卡勝利 +%%Y:nb:經濟.戰鬥經驗%% 經驗，強敵 +%%Y:nb:經濟.Boss戰鬥經驗%% 經驗，另有金幣獎勵。
  • 升級增加出戰人數，並提高商店出現高費棋子的機會。

商店與鎖定

  • 刷新依等級抽取費階，再從可用棋池選人；空費階的權重分配給其他費階。
  • 未買走的一至四費角色只在下一次刷新中迴避；五費不受影響。
  • 鎖定可保留貨架。解鎖不立即換貨，手動刷新或未鎖定的主線勝利才更新。
  • 標準與困難可在本局永久禁用角色，見難度與禁棋。

失敗與重試

  • 失敗不扣金幣、不掉棋子，回整備後可調整再戰。
  • 花 %%Y:nb:經濟.逆天改命費用%% 金「逆天改命」，重抽敵方陣容與戰鬥隨機種子；地圖不保證更換。
  • 主線通關後，仍可繼續遠征挑戰。

  • 關卡禁棋階段可少選或放棄，未用次數不保留。

羈絆組合

同羈絆棋子上陣達到人數門檻即可啟動。多數加成只作用於成員；「全隊」效果與光環依說明生效。

  • 星級羈絆：按星數計人數，如江南七怪的三星棋子計三人。
  • 反向羈絆：「獨行」只讓上陣成員中費用最高者獲得效果。
  • 裝備計作：部分裝備讓佩戴者計入羈絆，同一角色不重複計數。

五絕

兩名啟動成員攻防與速度加成；四名提高加成並獲得僵直護盾。

天龍三兄弟

喬峰、段譽、虛竹一起上陣，三人獲得生命與命中回內加成。

神鵰俠侶

楊過、小龍女一起上陣，成員低血時觸發玉女素心，短暫提高二人攻擊。

丐幫

主線勝利且有成員存活時產金；金額依檔位與存活成員的最高星級計算。

智將

主線勝利獲一次免費刷新，最多保留一次。高階可選戰場，並提高全隊生命與攻防。

紅顏

指定成員提供治療光環與敵方冷卻延長；高階再縮短友軍冷卻。成員以羈絆名單為準。

獨行反向羈絆

費用最高的獨行成員獲得攻擊、速度與防禦加成；戰至最後再提高攻擊與格擋。可搭配非獨行隊友。

江湖龍套

成員陣亡時殉爆傷敵，人數越多傷害越高。

裝備與內功

裝備怎麼來

  • 主線獎勵可免費選一件裝備，或付費改選標價的追加候選。數量與層級依難度而定。
  • 遠征通關也可獲得裝備。
  • 神兵天賦增加裝備獎勵，並開放四階神兵商店：標準第 %%Y:nb:神兵商店.通關後%% 關後、每件 %%Y:nb:神兵商店.價格%% 金；困難第 %%Y:hb:神兵商店.通關後%% 關後、每件 %%Y:hb:神兵商店.價格%% 金。

全部 %%C:equip%% 件裝備的效果與專屬加成，以遊戲內「裝備」為準。

裝備怎麼用

  • 每枚棋子能帶武器、防具各一件，裝新的自動換下舊的。
  • 注意專屬加成：如滅絕師太配倚天劍、黃蓉配打狗棒。
  • 部分裝備計作羈絆，如七星劍計作全真教、佛心甲計作少林寺。
  • 合成時各槽保留最高階裝備，其餘回庫存；出售棋子也會歸還裝備。

各難度的裝備獎勵時程

所有天賦都有基本獎勵，神兵另有追加。展開查看關卡、層級與價格。

絕招搜尋

內力充滿，施放當前星級威力最高的武功。每門絕招各有護身、控場、續航或反制效果。

遠征挑戰

共 %%C:challenge%% 關，整備時選好出戰隊伍即可挑戰。失敗無懲罰，不影響主線進度。

  • 每關獎勵只領一次，可獲金幣、棋子、升星、內功或裝備。
  • 候選數量依關卡而定；沒有適用目標的獎勵不會出現。
  • 可按當前缺口選擇挑戰；後期關卡敵人星級與裝備更強。
配隊小提示
  • 金幣取捨：開戰前決定留錢收息，或先花錢補強。
  • 鎖定候選：遇到想要卻買不起的棋子，可留到下一回合。
  • 配合絕招：護身、治療與控場能支援主力，站位也要配合效果範圍。
  • 湊出羈絆：低費棋子補齊關鍵檔位，可能比單換高費更有效。
  • 保護產金成員：丐幫需有人活到主線勝利才發金幣。
  • 裝備配角色：查看專屬加成與計作羈絆，再決定給誰。
戰鬥機制

棋子同時自動走位、出招。站位、冷卻與絕招效果共同決定戰局。

冷卻與動作

  • 武功對應的熟練度與輕功可縮短冷卻，但不低於攻擊形態的下限，也不縮短前搖、後搖。
  • 前搖結束才命中或發射投射物；後搖結束可重新走位。
  • 冷卻從動作開始時計算。冷卻與動作都結束，才能再次出招。

內力與絕招

出招、自然恢復、命中與受傷都能獲得內力。充滿後自動消耗全部內力施放絕招；封內期間無法獲得內力。各招效果見絕招搜尋。

傷害與防禦

  • 攻擊、武功威力與防禦決定基礎傷害，再計算暴擊、增減傷、護盾等效果。
  • 側背命中有額外傷害；投射物隨飛行時間略微衰減。
  • 閃避、格擋可避免命中；投射物也可能被彈反或互相抵消。

控制與保護

  • 近戰與主投射物命中可造成僵直，抗性與僵直護盾可縮短控制時間。
  • 低血量保護生效後，不再受到新的僵直或眩暈。
  • 戰鬥日誌可查施放、命中、傷害、狀態與陣亡紀錄。

攻擊形態

原版武功範圍在自走棋中對應以下攻擊方式；羈絆、裝備與絕招可再改變效果。

線／十字遠程直線穿透彈與較弱的扇形側彈。增加側彈。
面重擊追蹤目標的投射物。基礎投射物由一發增為兩發。

Windows 啟動問題

Windows 版怎麼啟動？

解壓後雙擊 金群自走棋.exe。搬移時請保留整個遊戲資料夾。

請先安裝 Microsoft Visual C++ x64 運行環境：下載 vc_redist.x64.exe。
