壹

緣起 · 這是什麼遊戲

關於本局棋

《金群自走棋》是開源項目「金庸群俠傳復刻版」（kys-cpp）中的自走棋玩法。擂鼓山上，蘇星河奉師命守護珍瓏棋局——棋盤之上，江湖群俠化為棋子，各展所長，自行廝殺；而你，才是執子之人。

招募棋子、排兵佈陣、湊齊羈絆、授予神兵內功，隨後坐看群俠自動交鋒。從江南七怪到掃地老僧，從華山五絕到天龍三兄弟，金庸筆下的英雄盡在一盤棋中。

純單機、無內購、失敗零懲罰，輸了隨時捲土重來。本頁隨 PC 版一同分發；若想立即體驗，網頁版打開即玩（推薦 Edge / Firefox / Chrome / Opera 瀏覽器），安卓與 Windows 亦有對應版本。

三分鐘上手

每回合：招募 → 佈陣 → 觀戰 → 提升

每一回合，你先在商店補強陣容，隨後棋子們自動出戰。你只管運籌，廝殺交給群俠。

叄

核心規則詳解

比遊戲內「遊戲說明」更展開一些；完整數值仍以遊戲內為準

棋子與升星

  • 棋子分一至五費，售價即費用（1費1金 …… 5費5金），越高費越難刷出。
  • 三枚相同一星合成二星，三枚二星再合三星；每顆額外星大幅提升屬性，另有固定加成，升星後脫胎換骨。
  • 出售按 費用 × 3星級-1 全額返還，換陣不虧。
  • 勝場成長：打贏主線、或首次通關遠征時，所有出戰棋子的個人勝場 +1。以普通難度當前配置為例，每個勝場值生命 +%%Y:nb:棋子成长.每胜生命%%、攻擊 +%%Y:nb:棋子成长.每胜攻击%%、防禦 +%%Y:nb:棋子成长.每胜防御%%、各項兵器熟練度 +%%Y:nb:棋子成长.每胜兵器%%、輕功 +%%Y:nb:棋子成长.每胜轻功%%；帶小數的按總勝場累計後向下取整。合成時只繼承三枚棋子裡最高的勝場，不會相加；部分羈絆還會按現有勝場再追加成長。

經濟與等級

  • 開局揣著 %%Y:nb:经济.初始金币%% 金；刷新商店一次 %%Y:nb:经济.刷新费用%% 金；%%Y:nb:经济.购买经验费用%% 金可買 %%Y:nb:经济.购买经验数量%% 點經驗。
  • 主線打贏後，按開戰前存款的 %%Y:nb:经济.利息百分比%%% 發利息，最多 %%Y:nb:经济.利息上限%% 金——打輸了沒有，遠征也不發。
  • 普通關卡勝利 +%%Y:nb:经济.战斗经验%% 經驗；打贏強敵（Boss）+%%Y:nb:经济.Boss战斗经验%% 經驗，外加一筆金幣。
  • 升級既能多上人，也會改變商店各費階的出現權重——高費棋子得等級上去了才刷得出來。

商店刷新、拒絕名單與禁棋

  • 刷新時先按你當前等級抽費階，再從該費階還能出現的角色裡挑人；這個費階要是沒人可挑，權重就勻給其他費階。
  • 這輪商店未買走的一至四費角色，會進入一次性的拒絕名單，只在下一次刷新時迴避；五費角色不受影響。
  • 標準與困難難度另有禁棋：指定角色會永久移出本局後續刷新池。禁棋只影響之後的商店，已在貨架上的棋子仍可購買；完整規則見下方「三種棋局難度 → 禁棋系統」。
  • 鎖定商店後，即使打贏主線也不會自動換貨；解除鎖定也不會立刻換貨。商店會在手動刷新，或下一次未鎖定的主線勝利後更新。

失敗零懲罰 · 逆天改命

  • 戰鬥失敗不扣金幣、不扣生命、不掉棋子，直接回到整備階段。
  • 換陣容、練級、買裝備，收拾好了再戰，直到打過去為止。
  • 也可以花 %%Y:nb:经济.逆天改命费用%% 金逆天改命，把下一場的敵方陣容和隨機種子重抽一遍。
  • 贏下全部主線關卡即「恭喜通關」；通關之後，遠征挑戰還能接著打。

第 %%Y:nb:无羁绊关卡%% 關的敵人沒有羈絆，開局可以放心穩紮穩打；逆天改命改的是敵方陣容與戰鬥隨機種子，地圖不保證會換。

規則與數值的關係

費用、成長、商店權重、關卡數、獎勵進度，這些都寫在難度配置裡；角色武功、羈絆、裝備、內功則各有各的內容配置。本頁講的是系統怎麼運轉，具體數值還是以當前版本遊戲內一覽為準。

肆

羈絆系統

同門同路，其利斷金

同羈絆的棋子一起上陣，湊夠人數就點亮對應檔位。要注意：大部分屬性和被動只加在真正計入羈絆的成員身上；標了「全隊」的才雨露均霑；治療光環這類效果，則是由成員當源頭去照顧隊友。這裡面還有三個門道：

  • 星級羈絆：成員每多一顆星即多計一人——如江南七怪，一枚三星棋子按三人計。
  • 反向羈絆：「獨行」會從已上陣的獨行成員中選費用最高者獨享效果；隊伍仍可搭配其他非獨行角色。
  • 裝備計作：部分裝備讓佩戴者「計作」某羈絆成員，缺一角也能成陣；同一角色不會因此重複計數。

五絕

不用湊齊五人：上陣兩名五絕，五絕成員就有攻防和速度加成；湊到四名數值更猛，還額外給一層能吃掉控制幀數的僵直護盾。

天龍三兄弟

喬峰、段譽、虛竹三人聚首，兄弟三人同享大量生命與命中回藍——只加兄弟三人，並非全隊加成。

神鵰俠侶

楊過、小龍女一起上陣後，我方第一次有人被打到低血時觸發玉女素心，二人短時間內攻擊暴增。

丐幫

打贏主線時，場上至少得有一名丐幫成員活著，才發這筆額外金幣；發多少，看羈絆檔位和存活成員裡的最高星級。

智將

每贏一場主線就攢一次免費刷新，不用會一直留著；高階還能自選戰場，並明明白白給全隊加生命、攻擊與防禦。趙敏、黃蓉皆在其列。

紅顏

紅顏看的是名單而不是性別——只有在配置名單裡的角色才算數，並非所有女性角色自動入陣。成員能帶來治療光環、受治療加速與冷卻干擾，高檔位才追加攻擊冷卻延長。

獨行反向羈絆

獨行俠上了好幾個，也只有費用最高的那位獨享攻速防加成；其他非獨行隊友不礙事。等他戰至最後，還會再漲攻擊與格擋。

江湖龍套

雜魚的逆襲：成員陣亡時殉爆傷敵，人越多炸得越狠。龍套也有春天。

以上僅為熱門羈絆舉例。全部 %%C:combos%% 種羈絆的成員、檔位與具體效果，以遊戲內「棋局總覽 → 羈絆一覽」為準。

裝備與內功

神兵利器，絕世心法

裝備怎麼來

  • 推主線會多次觸發裝備獎勵，候選數量和最高層級由難度配置決定。獎勵列表會直接列出可購買的追加候選，並在條目旁標明費用；選中後按標價扣除金幣。
  • 遠征挑戰的通關獎勵中也包含裝備。
  • 第 %%Y:nb:神兵商店.通关后%% 關（困難 %%Y:hb:神兵商店.通关后%% 關）後開放神兵商店，只售四階傳說裝備，每件 %%Y:nb:神兵商店.价格%% 金（困難 %%Y:hb:神兵商店.价格%% 金）。

全部 %%C:equip%% 件裝備的效果與專屬加成，以遊戲內「裝備管理」為準。

裝備怎麼用

  • 每枚棋子能帶武器、防具各一件，裝新的自動換下舊的。
  • 許多裝備對特定角色有專屬加成：如滅絕師太持倚天劍暴擊拉滿，黃蓉、洪七公、喬峰持打狗棒攻擊遠程化。
  • 部分裝備計作羈絆：七星劍計作全真教、真武劍計作真武七截陣、佛心甲計作少林寺……湊陣神器。
  • 升星合成時，每個裝備槽只留層級最高那件，其餘自動回庫存；賣棋子時裝備也會自動卸下來。

內功心法

每擊敗一位強敵（每 %%Y:nb:进度.Boss间隔%% 關一位），就能從隨機 %%Y:ng:选择数量%% 本還沒學過的內功裡挑一本；隨著主線進度推進，候選內功的最高層級也會提高。獎勵列表會直接列出可購買的追加候選，每本標價 %%Y:ng:追加選項費用%% 金，選中後直接扣款。內功一經習得，全隊生效，後期陣容強不強，很大程度就看它了。

共 %%C:neigong%% 種內功、分四個層級，具體效果以遊戲內「棋局總覽 → 查看內功」為準。

  • 困難難度限定離線對戰：導出自己的存檔陣容、導入朋友的存檔，就能異步 PVP 一較高下（存檔帶校驗）。

遠征挑戰

不佔主線回合的額外試煉

共 %%C:challenge%% 關額外挑戰，整備階段只要手裡有出戰棋子就能打，輸了不罰，也不耽誤主線進度。每關獎勵只能領一次；給幾個候選看關卡配置，並非固定三選一，可能是金幣、棋子、升星、內功或裝備——哪項當前沒有合法目標，那一項就乾脆不出現。從單挑三星喬峰的「聚賢莊內」，到全員三星神裝的「九陽宗師」，一關比一關難纏。

挑戰小貼士

  • 挑戰前記得先選好出戰陣容。
  • 前期優先打「聚賢莊內」「慕容世家」，獎勵的升星與棋子能快速成型。
  • 後期關卡全員三星還帶神裝，是檢驗陣容的試金石。
  • 獎勵關卡各有側重，缺什麼補什麼。

江湖錦囊

老玩家的經驗之談
  • 攢錢吃息：主線勝利才按開戰前存款結算利息，上限 %%Y:nb:经济.利息上限%% 金。開戰後想攢就晚了——開戰前就想好，這筆錢留著吃息還是換成即時戰力。
  • 鎖定商店：遇到想要卻買不起的棋子，鎖定留到下回合，別硬刷新。
  • 看中的趁早買：沒買走的一至四費角色，拒絕名單只管緊接著的一次刷新，並非永久禁棋；五費角色不受此限。
  • 賣棋不虧：出售全額返還，前期打工棋子放心換。
  • 連敗不慌：失敗零懲罰，先把等級和裝備補起來再戰，或花 %%Y:nb:经济.逆天改命费用%% 金逆天改命換個對手。
  • 羈絆優先：低費棋子湊出關鍵羈絆，往往強過散兵遊勇的高費棋子。
  • 智將理財：智將羈絆每贏一場主線送一次免費刷新，不用就先留著——但不會越攢越多。
  • 丐幫開源：丐幫成員得活到主線勝利結算才產金；別讓唯一的丐幫棋子太早倒下。
  • 升級再追夢：五費宗師只在高等級商店出現，想追張三丰、掃地老僧先升級。
  • 裝備給對人：專屬裝備配專屬角色（倚天劍給滅絕、打狗棒給黃蓉），才能觸發角色限定的額外效果。
拾

自動戰鬥機制

供復盤與查證的戰鬥參考

開戰後沒人閒著：所有棋子按幀同時行動——接敵、出招、打出近戰判定或放飛投射物，再一一結算命中、傷害與狀態。這一章講的是這些機制怎麼串起來；具體幀數與倍率可能隨版本調整，不必死記。

勝負判定：同幀全滅與時間上限

  • 雙方在同一幀全部陣亡時，玩家 1 勝利，不按平手處理。
  • 戰鬥若持續到第 99,999 幀仍未分出勝負，立即因時間耗盡結束，玩家 1 判負。

熟練度、輕功與冷卻

每門武功都對應一種熟練度：拳掌武功看拳掌，御劍武功看御劍，其他類別同理。兩次出招之間的冷卻先由攻擊形態決定，再由對應熟練度和輕功縮短，最後計算額外的冷卻縮減或延長；冷卻不會低於該攻擊形態的下限。這些屬性只影響下一次何時能出招，不會縮短出招前搖或收招後搖。

內力與絕招循環

出招、自然恢復、命中敵人和承受傷害都能獲得內力，回內加成會提高這些收益。內力充滿後，棋子會自動消耗全部內力施放絕招。封內期間無法獲得內力，因此下一次絕招會延後。不同攻擊形態的絕招變化，見下方「點 / 線 / 十字 / 面」說明。

前搖與後搖如何決定

  • 前搖看的是這次實際採用的攻擊形態，跟武功叫什麼名字無關。近戰、追蹤彈、直線彈、突進各有各的基礎施放幀；出手瞬間還會上下浮動一絲絲，免得全場棋子齊刷刷同幀出手，跟排練過似的。
  • 前搖結束後才會真正出手：近戰這時才生成命中判定，遠程這時才放出投射物，突進這時才衝出去。如果原目標已經倒下或無法攻擊，招式會直接結束，或根據攻擊形態改選其他目標。
  • 後搖是出手後那點收勢時間。普通攻擊的收勢大家都一樣長，突進則按自己的衝勢收尾；收完勢就能重新走位——但別誤會，這不代表冷卻已經轉好。
  • 總冷卻從動作一開始就同步倒數，前搖後搖都算在裡面；冷卻歸零、當前動作也做完，棋子才能接下一招。所以一招的完整節奏，並非「前搖 + 後搖 + 冷卻」三段簡單相加。

「點 / 線 / 十字 / 面」在自走棋裡的實際解釋

這些名稱來自原版回合制武功資料；自走棋會把它們轉換為下表的即時攻擊方式。棋盤面板有時簡稱為「輕 / 重 / 遠」，完整名稱是「輕擊 / 重擊 / 遠程」。

資料範圍棋盤稱呼自走棋實際行為絕招時的主要變化
點（0）輕（輕擊）近身肉搏；連續普通近戰打到第三下，會變成一記追擊式的強化打擊。這一擊必定強化，還會補上一記慢半拍的近身濺射。
線 / 十字（1 / 2）遠（遠程）目前都會變成直線穿透的投射物，順帶幾枚較弱的扇形側彈；「十字」並不會真的向上下左右各射一條線。側彈更多，但仍是一片朝目標方向展開的穿透彈幕。
面（3）重（重擊）變成追蹤投射物，盯著選定目標或附近的備選目標追，並非全屏轟炸。基礎追蹤彈從一發變兩發；想要更多追加彈，得看武功、羈絆或裝備的本事。

部分羈絆與裝備還會帶來遠程化、滑步攻擊、閃擊、追加彈、連鎖彈、反彈這些本事，把上面的基礎行為改出各種花樣。

一次命中如何結算

  • 先拿攻擊、武功威力和目標防禦算出基礎傷害；有穿甲的話，參與計算的防禦先打個折。
  • 投射物飛得越久，威力略微衰減；從側面或背後命中還有額外傷害——所以站位和混戰中的朝向真不是小事。
  • 然後才輪到一堆修正挨個結算：熟練度差、技能增傷、暴擊、固定加減傷、百分比減傷、護盾、單次承傷上限。
  • 這一下也未必打得實：閃避讓它直接落空，格擋能整下取消；遠程攻擊還可能被彈反，甚至和敵方投射物在空中互相抵消、削弱。

僵直、眩暈與低血保護

  • 被主投射物或近戰打中會短暫僵直，絕招主命中的基礎僵直更長；眩暈、擊退、封內、中毒、流血則來自具體效果。
  • 僵直抗性按比例縮短被控時間；護盾能提供額外抗性，僵直護盾則先替你吃掉一定控制幀數。
  • 血低於一定比例後，棋子不會再中新的僵直或眩暈——給殘血留條活路，免得被一路控到陣亡。
  • 每次施放、命中、傷害、狀態、抵消與陣亡都帶幀號寫進戰鬥日誌；這一局輸在接敵、輸出循環還是控制鏈，翻翻日誌就有數。
