缘起 · 这是什么游戏

关于本局棋

《金群自走棋》是开源项目「金庸群侠传复刻版」（kys-cpp）中的自走棋玩法。擂鼓山上，苏星河奉师命守护珍珑棋局——棋盘之上，江湖群侠化为棋子，各展所长，自行厮杀；而你，才是执子之人。

招募棋子、排兵布阵、凑齐羁绊、授予神兵内功，随后坐看群侠自动交锋。从江南七怪到扫地老僧，从华山五绝到天龙三兄弟，金庸笔下的英雄尽在一盘棋中。

纯单机、无内购、失败零惩罚，输了随时卷土重来。本页随 PC 版一同分发；若想立即体验，网页版打开即玩（推荐 Edge / Firefox / Chrome / Opera 浏览器），安卓与 Windows 亦有对应版本。

三分钟上手

每回合：招募 → 布阵 → 观战 → 提升

每一回合，你先在商店补强阵容，随后棋子们自动出战。你只管运筹，厮杀交给群侠。

核心规则详解

比游戏内「游戏说明」更展开一些；完整数值仍以游戏内为准

棋子与升星

  • 棋子分一至五费，售价即费用（1费1金 …… 5费5金），越高费越难刷出。
  • 三枚相同一星合成二星，三枚二星再合三星；每颗额外星大幅提升属性，另有固定加成，升星后脱胎换骨。
  • 出售按 费用 × 3星级-1 全额返还，换阵不亏。
  • 存活棋子每胜一场还会成长：生命 +%%Y:nb:棋子成长.每胜生命%%、攻击 +%%Y:nb:棋子成长.每胜攻击%%、防御 +%%Y:nb:棋子成长.每胜防御%%。

经济与等级

  • 初始 %%Y:nb:经济.初始金币%% 金；刷新商店 %%Y:nb:经济.刷新费用%% 金；购买经验 %%Y:nb:经济.购买经验费用%% 金换 %%Y:nb:经济.购买经验数量%% 点。
  • 存款按 %%Y:nb:经济.利息百分比%%% 生息，每回合上限 %%Y:nb:经济.利息上限%% 金——攒钱也是战斗力。
  • 普通胜利 +%%Y:nb:经济.战斗经验%% 经验，强敌（Boss）胜利 +%%Y:nb:经济.Boss战斗经验%% 经验与额外金币。
  • 最高 %%Y:nb:最高等级%% 级；等级 = 出战人数上限，也决定商店品质——高费棋子要先升级才刷得到。

武功与战斗

  • 武功分拳掌 / 剑法 / 刀法 / 奇门四类，棋子对应熟练度越高，该类武功冷却越短。
  • 攻击范围分点（单体）/ 线（直线穿透）/ 十字 / 面（全范围），自动映射轻击、远程、重击等操作。
  • 轻击带连击：第 3 次命中强化为 2 倍伤害；重击扇形弹射；远程直线穿透。
  • 内力满触发绝招：选最强武功、伤害 ×2、追加 ±30° 追踪弹射，随后内力清零。
  • 僵直使棋子完全无法行动；部分羁绊提供僵直抗性甚至免控。

失败零惩罚 · 逆天改命

  • 战斗失败不扣金币、不扣生命、不掉棋子，直接回到整备阶段。
  • 可以换阵容、练级、买装备后再战，直到打过去为止。
  • 也可以花 %%Y:nb:经济.逆天改命费用%% 金逆天改命，重抽下一场的敌方随机种子与阵容。
  • 通关条件：赢下全部主线关卡即「恭喜通关」，之后仍可继续远征挑战。

第 %%Y:nb:无羁绊关卡%% 关敌人无羁绊，开局可放心稳扎稳打。

羁绊系统

同门同路，其利断金

同羁绊的棋子同时上阵，凑齐人数即激活羁绊效果；多档阈值逐级升级，全员受益。其中门道有三：

  • 星级羁绊：成员每多一颗星即多计一人——如江南七怪，一枚三星棋子按三人计。
  • 反向羁绊：「独行」只取上阵成员中费用最高者，独得全部效果，一人即是绝世独立。
  • 装备计作：部分装备让佩戴者「计作」某羁绊成员，缺一角也能成阵。

五绝

东邪西毒南帝北丐中神通齐上阵：攻击、防御、速度全面提升，四绝更得僵直护盾。华山论剑，名不虚传。

天龙三兄弟

乔峰、段誉、虚竹三人聚首：全队生命大涨、命中回蓝。兄弟同心，其利断金。

神雕侠侣

杨过、小龙女双剑合璧：友方低血时触发玉女素心，攻击暴增反败为胜。

丐帮

天下第一大帮最会过日子：上阵即每场额外产出金币，越打越富。

智将

运筹帷幄：每回合免费刷新商店，高阶更可自选战场，全队属性提升。赵敏、黄蓉皆在其列。

红颜

全女性阵容：治疗光环持续回血，受治疗加速，还能延长敌方攻击冷却。

独行反向羁绊

只遣一名绝世高手上阵，独得攻击、速度、防御加成；若战至最后存活，再添攻击与格挡。

江湖龙套

杂鱼的逆袭：成员阵亡时殉爆伤敌，人越多炸得越狠。龙套也有春天。

装备与内功

神兵利器，绝世心法

装备怎么来

  • 主线第 3 / 6 / 9 / 12 / 15 / 18 / 21 关后各触发一次装备奖励：四件候选挑一件，可花 4 金刷新候选，层级随进度提高。
  • 远征挑战的通关奖励中也包含装备。
  • 第 %%Y:nb:神兵商店.通关后%% 关（困难 %%Y:hb:神兵商店.通关后%% 关）后开放神兵商店，只售四阶传说装备，每件 %%Y:nb:神兵商店.价格%% 金（困难 %%Y:hb:神兵商店.价格%% 金）。

全部 %%C:equip%% 件装备的效果与专属加成，以游戏内「装备管理」为准。

装备怎么用

  • 每枚棋子可佩戴武器、防具各一件，装新换旧自动替换。
  • 许多装备对特定角色有专属加成：如灭绝师太持倚天剑暴击拉满，黄蓉、洪七公、乔峰持打狗棒攻击远程化。
  • 部分装备计作羁绊：七星剑计作全真教、真武剑计作真武七截阵、佛心甲计作少林寺……凑阵神器。
  • 棋子升星合成时装备自动继承；出售棋子时装备自动卸下，不浪费。

内功心法

每击败一位强敌（每 %%Y:nb:进度.Boss间隔%% 关一位），即可从随机 %%Y:ng:选择数量%% 本内功中挑选一本，花 %%Y:ng:刷新费用%% 金可重抽候选；强敌越靠后，可选层级越高。内功一经习得，全队生效，是后期阵容强度的关键。

共 %%C:neigong%% 种内功、分四个层级，具体效果以游戏内「棋局总览 → 查看内功」为准。

远征挑战

不占主线回合的额外试炼

共 %%C:challenge%% 关额外挑战，随时可打、失败无惩罚；每关奖励只能领一次，通关奖励三选一（金币 / 棋子 / 升星 / 内功 / 装备）。从单挑三星乔峰的「聚贤庄内」，到全员三星神装的「九阳宗师」，难度层层加码。每关的敌方阵容与奖励，以游戏内「远征挑战」界面为准。

挑战小贴士

  • 挑战前记得先选好出战阵容。
  • 前期优先打「聚贤庄内」「慕容世家」，奖励的升星与棋子能快速成型。
  • 后期关卡全员三星还带神装，是检验阵容的试金石。
  • 奖励关卡各有侧重，缺什么补什么。

江湖锦囊

老玩家的经验之谈
  • 攒钱吃息：存款每回合生息，上限 %%Y:nb:经济.利息上限%% 金。前期稳住本金，中后期钱滚钱。
  • 锁定商店：遇到想要却买不起的棋子，锁定留到下回合，别硬刷新。
  • 看中的趁早买：回合结束没买的棋子会进入「拒绝名单」，影响后续刷新概率。
  • 卖棋不亏：出售全额返还，前期打工棋子放心换。
  • 连败不慌：失败零惩罚，先把等级和装备补起来再战，或花 %%Y:nb:经济.逆天改命费用%% 金逆天改命换个对手。
  • 羁绊优先：低费棋子凑出关键羁绊，往往强过散兵游勇的高费棋子。
  • 智将理财：智将羁绊每回合免费刷新，省下大量刷新费。
  • 丐帮开源：丐帮羁绊每场额外产金，越早凑齐越赚。
  • 升级再追梦：五费宗师只在高等级商店出现，想追张三丰、扫地老僧先升级。
  • 装备给对人：专属装备配专属角色（倚天剑给灭绝、打狗棒给黄蓉），战力翻倍。
