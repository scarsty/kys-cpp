# 效果規則簡式語法設計（歷史）

狀態：已由[《效果規則通用簡式與舊語法移除設計》](效果規則通用簡式與舊語法移除設計.md)取代。

這份文件原先記錄第一代簡式的可行性評估。該版本曾將 rule-level `事件`、action／condition 外層 `類型`及 `屬性加成.固定` 視為可用格式；這些語法已全數移除，不是目前的作者契約。詳細的歷史設計可由 Git 記錄查閱，不在現行文件保留已失效的 YAML 範例。

現行效果規則只有一種作者外形：

- rule 以 `時機` 選擇事件。
- action 以具名 action node 表達。
- condition 使用 scalar、單參數或具名 payload。
- `屬性加成` 的固定加算屬性直接放在該 node 下，只有百分比加算放在 `百分比` 分組。
- selector、攻擊執行行為與其他 payload 內部 tagged union 仍可使用自己的 `類型`。

```yaml
- 時機: 命中
  目標: 命中目標
  條件:
    - 僅限主彈道
  動作:
    - 套用狀態:
        狀態: 寒毒
        持續幀數: 90
        合併方式: 增加層數
    - 屬性修正:
        屬性: 攻擊
        方式: 固定加算
        數值: 10
```

作者語法的完整時機表、欄位契約、descriptor 架構、YAML Schema 與舊語法 rejection 要求，均以後續通用設計為準。
