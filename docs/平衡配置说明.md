# 平衡配置说明

本文档介绍如何通过修改配置文件来调整自走棋的数值平衡。

## 配置文件

| 文件 | 用途 |
|------|------|
| `config/chess_balance_easy.yaml` | 简单难度平衡配置 |
| `config/chess_balance_normal.yaml` | 标准难度平衡配置 |
| `config/chess_balance_hard.yaml` | 困难难度平衡配置 |
| `config/chess_pool.yaml` | 棋池配置（角色ID与费用等级） |
| `config/chess_pool_easy.yaml` | 简单难度专用棋池配置 |
| `config/chess_neigong.yaml` | 内功配置 |
| `config/chess_challenge.yaml` | 远征挑战配置 |

游戏会按当前所选难度自动读取对应的平衡配置。如果文件格式有误，控制台会输出错误信息。

## 棋手天賦與裝備獎勵

`config/chess_talents.yaml` 集中四種天賦的數值。平衡配置的結構鍵已統一為繁體中文，載入器不接受舊簡體別名。

```yaml
棋手天賦:
  預設: 神兵
  可選: [神兵, 晚成, 賭徒, 中堅]
玩家裝備獎勵:
  基本:
    - 關卡: 3
      最低層級: 1
      最高層級: 1
      選項數量: 4
      追加選項費用: 4
  天賦額外:
    神兵:
      - 關卡: 30
        最低層級: 3
        最高層級: 4
        選項數量: 4
        追加選項費用: 4
```

以上為結構範例，完整時程以各難度檔案為準。所有天賦在第 3、11、19、27 關後取得基本裝備獎勵；神兵另有第 7、15、23 關後獎勵，困難再加第 30 關。每份表必須按關卡嚴格遞增，抽取同時遵守最低及最高層級。簡單、標準只有神兵；困難可選四種天賦。

神兵商店各難度皆為每件 30 金，簡單及標準於第 27 關後開放、困難於第 31 關後開放。只有具備商店能力的天賦可使用。

詳細公式、隨機流及升星保證規則見 [棋手天賦設計](chess-player-talent-design.md)。配置 schema 位於 `schemas/chess_talents.schema.json` 及 `schemas/chess_balance.schema.json`。

## 星級加成

控制棋子升星后的属性加成。每颗额外星同时按百分比和固定值提升属性。

```yaml
星級加成:
  生命倍率: 0.4       # 每星+40%生命
  攻擊倍率: 0.4       # 每星+40%攻击
  防禦倍率: 0.4       # 每星+40%防御
  武功倍率: 0.4       # 每星+40%拳掌、御劍、耍刀、特殊、暗器
  速度倍率: 0.25      # 每星+25%速度
  固定生命: 275       # 每星额外固定生命
  固定攻擊: 55        # 每星额外固定攻擊
  固定防禦: 35        # 每星额外固定防禦
```

例如2星棋子的生命 = 基础生命 × (1 + 0.4) + 275。

## 經濟

控制金币收入和花费。

```yaml
經濟:
  初始金幣: 15
  刷新費用: 2           # 刷新商店花费
  購買經驗費用: 5       # 购买经验花费
  購買經驗數量: 5       # 每次购买获得的经验
  戰鬥經驗: 2           # 每次战斗自动获得的经验
  Boss戰鬥經驗: 6       # Boss战胜利获得的经验
  戰鬥獎勵基礎: 4       # 胜利奖励基础金币
  戰鬥獎勵增長: 12      # 最后一关比第一关多给的金币(逐关递增)
  Boss獎勵加成: 5       # Boss战额外奖励金币
  利息百分比: 10        # 每回合按存款给利息(百分比)
  利息上限: 3           # 利息最多给几金币
```

## 棋子費用

```yaml
棋子費用:
  各費價格: [1, 2, 3, 4, 5]   # 1~5费棋子的购买價格
  星級倍率: 3                   # 出售时星级價格倍率
```

出售價格 = 费用 × 倍率^星级 × 数量

## 经验与等级

```yaml
經驗表: [1, 5, 10, 15, 20, 25, 30, 35, 40]
最高等級: 9
```

經驗表第N项为从N级升到N+1级所需的经验。升级后经验清零重新累积。等级决定出战人数上限和商店刷新品质。

## 容量

```yaml
背包上限: 10       # 备战席最大棋子数
最低出戰人數: 2    # 出战人数下限（等级低于此值时使用）
```

## 商店權重

每行对应一个等级（0~9级），5个数字分别是1~5费棋子的出现权重。

```yaml
商店權重:
  - [85, 15, 0, 0, 0]      # 0级
  - [70, 30, 0, 0, 0]       # 1级
  - [60, 35, 5, 0, 0]       # 2级
  # ...以此类推
```

权重之和应为100。

## 敵人表

每关敌人以列表形式直接配置，每个敌人为 `[费用tier, 星级star]`。

```yaml
敵人表:
  - [[1, 1], [1, 1]]                          # 第1关
  - [[1, 1], [2, 1]]                          # 第2关
  - [[1, 1], [2, 1]]                          # 第3关
  - [[1, 2], [2, 1], [2, 1]]                  # 第4关(BOSS)
  # ...以此类推
```

每隔 `Boss間隔` 关出现一次Boss战。敌人数量和强度完全由此表决定。

## 敵人裝備

敵人裝備按關卡逐级开放。每个条目支持以下字段：

```yaml
敵人裝備:
  - 關卡: 20
    最高層級: 3
    裝備數量: 1
  - 關卡: 29
    最高層級: 4
    裝備數量: 7
    雙裝備: true
```

- `關卡`: 从第几关开始生效。
- `最高層級`: 可掉落的装备 tier 上限。
- `裝備數量`: 本阶段会被装备的敌人数。
- `雙裝備`: 设为 `true` 时，每个被选中的敌人同时获得一件武器和一件防具；省略或设为 `false` 时，仍按原逻辑随机发放武器或防具中的一种。

## 進度

```yaml
進度:
  總關卡數: 28       # 通关所需總關卡數
  Boss間隔: 4        # 每隔几关出现Boss
```

## 内功配置 (chess_neigong.yaml)

```yaml
追加選項費用: 4      # 選擇額外內功候選時的花費
選擇數量: 3          # 每次提供的免費與額外內功候選數量
Boss可選層級:        # boss序号(0-indexed) -> 可选tier列表
  0: [1]
  1: [1, 2]
  2: [1, 2, 3]
  3: [1, 2, 3, 4]
```

`層級分配` 将武功ID分配到不同层级，`效果` 定义每个武功的战斗效果。

## 远征挑战配置 (chess_challenge.yaml)

```yaml
远征挑战:
  - 名称: "聚贤庄内"
    描述: "挑战乔峰"
    敌人: [[50, 3]]           # [角色ID, 星级]
    奖励:
      - 类型: 获取金币
        数值: 10
      - 类型: 升星1到2
        最高費用: 2
      - 类型: 获取内功
        最高層級: 1
```

奖励类型：`获取金币`、`获取棋子`、`获取内功`、`升星1到2`、`升星2到3`。
