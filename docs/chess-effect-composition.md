# 棋戰效果組合

正式配置使用具名的玩法效果。獨立能力放在 `效果` 列表中的不同項目；共同的觸發事件不代表必須寫成同一個 C++ 效果。

## 日常數值調整

易筋神功與神照功共用 `出招護盾`。易筋的格擋加成另列一項：

```yaml
- 武功: 108
  名稱: 易筋神功
  效果:
    - 類型: 出招臨時屬性加成
      屬性: 格擋率
      百分比: 25
      持續幀數: 60
    - 類型: 出招護盾
      每星護盾: 70
```

護盾支援 `固定護盾`、`每星護盾`、`生命護盾百分比`；省略的數值項為 0。例如：

```yaml
- 類型: 出招護盾
  固定護盾: 20
  每星護盾: 70
  生命護盾百分比: 5
```

每個目標得到 `20 + 70 × 施招者星級 + 目標血量上限 × 5%`。三項先合計，再執行一次資源變更。

`出招治療自身` 同樣支援 `固定治療`、`每星治療`、`生命治療百分比`。治療合計後才交給既有治療流程套用禁療、受療修正及生命上限，不拆成多次治療。浣花的 `治療淨化低血友軍` 也使用此計算方式，並保留同一次選人後治療及淨化的順序。

## 可重用效果

| 效果 | 用法 |
|---|---|
| `出招臨時屬性加成` | 自身的屬性、百分比、持續幀數；重複施加刷新時間 |
| `出招全隊臨時屬性加成` | 相同屬性加成，目標為全隊 |
| `出招疊加屬性` | 屬性、每層百分比、層數上限；各效果獨立設定 |
| `出招治療自身` | 固定值、每星值、生命比例治療 |
| `出招護盾` | 固定值、每星值、生命比例護盾 |
| `出招狀態護盾`、`出招僵直護盾`、`出招全隊僵直護盾` | 相同數值項，分別套用至對應護盾資源 |
| `出招淨化自身` | 清除自身負面效果 |
| `出招全隊解控` | 清除全隊控制及當前僵直，保留位置與動作 |
| `出招疊加純粹傷害` | 增加命中附加純粹傷害的狀態層數 |
| `出招殘影攻擊` | 取得有時限的殘影攻擊狀態；不附帶速度或閃避 |
| `主彈命中擊退`、`主彈命中弱化傷害` | 打狗的主彈傷害前操作 |
| `友軍治療光環`、`友軍減冷卻光環` | 可分別設定半徑、間隔及數值；均排除自身 |
| `七星歸一` | 同羈絆共計出招，每七次由存活成員向觸發者目標各發射一道獨立劍氣；不觸發其他效果。開場護盾與陣亡補盾仍獨立保留 |
| `同羈絆陣亡補盾` | 指定數量的同羈絆友軍死亡後補盾 |
| `同羈絆陣亡屬性加成` | 同羈絆友軍死亡後，增加指定攻擊或防禦點數 |

臨時及疊層屬性支援：`攻擊`、`防禦`、`速度`、`格擋率`、`閃避率`、`暴擊率`、`暴擊傷害`。攻擊、防禦、速度使用比例加成；其餘使用百分點加成。未知名稱及數字形式的屬性索引均拒絕載入。

`主彈命中弱化傷害` 保留打狗的傷害前觸發、最終傷害階段及刷新時間。`命中削弱敵方傷害` 保留成功造成生命傷害後觸發、防禦前階段及獨立施加。兩者不可僅因名稱相近而互換。

## 承傷與閃避上限

百分比減傷共用 80% 的總上限，以 10,000 基點記錄剩餘傷害倍率，最低為 2,000 基點。`承傷百分比修正` 的負值、`減傷` 屬性、百分比吸收、低於 100% 的傷害乘算及護衛轉移減傷均使用此預算；轉移時保留原目標已使用的減傷預算。正值承傷修正仍會增加傷害，不重設減傷預算。

一般命中的暴擊前出傷百分點及基礎承傷百分點各自先合計，其餘階段按修正順序套用；直接傷害交易按既有增傷及減傷欄位合計，乘算則逐層套用。各減傷階段及乘算層相乘，再限制合計減傷。例如兩個 50% 減傷階段合計減傷 75%，再加一個 50% 減傷階段時只會達到 80% 的總上限。`固定承傷修正` 與 `失血固定承傷修正` 扣除點數，不列入百分比預算，仍可把傷害抵消至零。防禦屬性的攻防曲線、護盾、無敵、格擋與單次承傷封頂沿用各自的規則。

閃避率在結算所有屬性、針對攻擊者的修正與區域加成後限制在 0% 至 80%，隨機值嚴格小於最終閃避率才成功。必中攻擊沿用忽略閃避的規則。

## 已遷移的組合

- 易筋：格擋加成與護盾。
- 九陽：治療與純粹傷害疊層。
- 太玄、九陰：各項臨時屬性。
- 葵花：速度、閃避、殘影狀態。
- 先天：淨化、狀態護盾、僵直護盾。
- 逍遙遊：全隊解控、僵直護盾、速度。
- 打狗：擊退與傷害弱化。
- 紅顏：治療光環與減冷卻光環；目前仍使用相同間隔。
- 全真：開場護盾、七星歸一合擊、陣亡補盾。七星歸一共計同門出招，劍氣採各成員自身攻擊力與配置的「武功威力」（目前 300），沿用「攻擊力＋武功威力÷3」及後續攻防公式，走正常攻防、閃避與格擋流程；不觸發出招或命中連鎖。外觀由「特效編號」配置，目前為 48。
- 苗家：暴擊率與暴擊傷害疊層。
- 明教：陣亡增加攻擊與防禦。
- 天山折梅手使用共用疊層屬性；混元使用共用自身治療。

以上舊組合名稱已移除，沒有相容別名。對應 JSON Schema 由效果登錄資料產生，與解析器共用屬性選項及預設值。

## 應保留的組合邊界

- 同一批目標：浣花、青囊的治療與淨化；銀索金鈴的牽引與眩暈；陰險的最強敵人壓制。
- 共享狀態生命週期：寒毒、枯骨、降龍戰意的共同層數、移除與刷新規則。
- 共享區域：護陣與干擾區域的座標、半徑、存續時間及來源死亡處理。
- 有先後關係的機制：回內後滿內治療、引毒後再施毒、蓄力與消耗、吸收與返還。
- 攻擊附帶的能力：左右互搏追擊時的抵擋、毒爆、螺旋流血及追蹤爆炸的負面效果。

新增效果時先檢查既有元件能否組合。只有新的玩法機制才需要新增 C++ 定義；一般數值、屬性、持續時間或既有能力的搭配應由配置完成。
